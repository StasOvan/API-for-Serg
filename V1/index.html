API генератор случайных значений name, city, phone, email

Все эндпоинты возвращают чистый текст (Content-Type: text/plain; charset=utf-8) и не требуют авторизации.
Параметры "(по умолчанию)" можно не указывать.

GET /API/V1/GET/random-name

возвращает случайное русское имя

ПараметрыОписаниеРезультат
(без параметров) имя с большой буквы, кириллицей
?capitalize=true имя с большой буквы (по умолчанию)
?capitalize=false имя с маленькой буквы
?transliter=true транслитерация имени латиницей
?transliter=false без транслитерации (по умолчанию)
?capitalize=false&transliter=true имя латиницей с маленькой буквы
?capitalize=true&transliter=true имя латиницей с большой буквы
Результат запроса:
пока пусто ..

GET /API/V1/GET/random-city

возвращает случайный российский город

ПараметрыОписаниеРезультат
(без параметров) город с большой буквы, кириллицей
?capitalize=true город с большой буквы (по умолчанию)
?capitalize=false город с маленькой буквы
?transliter=true транслитерация названия латиницей
?transliter=false без транслитерации (по умолчанию)
?capitalize=false&transliter=true город латиницей с маленькой буквы
?capitalize=true&transliter=true город латиницей с большой буквы
Результат запроса:
пока пусто ..

GET /API/V1/GET/random-phone

возвращает случайный мобильный номер РФ в формате +7 (9XX) XXX-XX-XX

ПараметрыОписаниеРезультат
(без параметров) форматированный номер
?raw=false форматированный номер (по умолчанию)
?raw=true номер без форматирования, например +79012310856
Результат запроса:
пока пусто ..

GET /API/V1/GET/random-email

возвращает случайный email

ПараметрыОписаниеРезультат
(без параметров) случайный email
Результат запроса:
пока пусто ..

Технические детали:

  • Формат ответа: text/plain; charset=utf-8 — тело ответа содержит только значение, без JSON и кавычек.
  • Метод запроса: GET.
  • Авторизация не требуется.
  • Для параметров типа boolean значение true (без учёта регистра) включает опцию; любое другое значение или отсутствие параметра — выключает.
